# Mini-Proyecto-2-Bioinform-tica-2026
Mini-Proyecto 2 de Bioinformática (UNSTA, 2026): análisis del dataset Breast Cancer Wisconsin (Diagnostic) con data mining y machine learning para clasificar tumores de mama como benignos o malignos. Incluye PCA, árbol de decisión, Random Forest con OOB, SVM y red neuronal.
